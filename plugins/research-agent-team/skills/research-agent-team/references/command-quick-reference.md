# Command Quick Reference

Stage 0 defines command names so CLI, schemas, documentation, and future MCP
tools agree on the public surface.

Project lifecycle:

- `create_project`
- `open_project`
- `switch_operating_mode`
- `pause_project`
- `resume_project`

Topology:

- `show_team_topology`
- `add_senior`
- `add_junior`
- `retire_senior`
- `retire_junior`

Tasking, governance, knowledge, and experiments:

- `assign_task`
- `approve_checkpoint`
- `reject_checkpoint`
- `request_status`
- `generate_report`
- `sync_knowledge_base`
- `rebuild_graph`
- `run_experiment`
- `review_experiment`
